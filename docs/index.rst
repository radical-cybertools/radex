RaDex Documentation
===================

The RADICAL Data Exchange (RaDex) is a middleware approach to in-memory data exchange
designed for high-performance computing platforms. We support both the Redis and
DragonHPC's Distributed Dictionary as backends, though support for other similar
solutions may be possible.
